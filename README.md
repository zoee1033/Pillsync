# 💊 PillSync

### AI-Enabled Smart Medication Management & Adherence Platform

PillSync is a smart healthcare platform designed to simplify medication management for patients, caregivers, and administrators.

The system combines prescription OCR, intelligent medication tracking, treatment management, reminders, refill prediction, browser notifications, caregiver coordination, and administrative monitoring into a unified platform.

---

## 🚀 Project Overview

Managing multiple medicines can become difficult, especially when patients need to remember:

- Which medicine to take
- How much medicine to take
- When to take it
- How long the treatment should continue
- Whether enough medicine is available
- When a medicine needs to be restocked
- Whether a caregiver is monitoring their medication
- Whether reminders and notifications are being delivered correctly

PillSync addresses these challenges through a centralized medication management platform.

The platform provides separate experiences for:

👤 **Patients**  
👨‍⚕️ **Caregivers**  
🛡️ **Administrators**

# ✨ Key Features

## 👤 Patient Module

Patients can manage their complete medication lifecycle from a single dashboard.

### Dashboard

The patient dashboard provides an overview of:

- Active treatments
- Medicines
- Upcoming reminders
- Medication status
- Refill information
- Notifications
- Caregiver relationships

### 💊 Medicine Management

Patients can:

- Add medicines
- Edit medicines
- View medicine details
- Track medicine quantity
- View dosage information
- Monitor daily consumption
- View remaining treatment days
- View medicine health/status
- Monitor refill requirements

### ⏰ Medication Reminders

Patients can:

- Create medication reminders
- Edit reminders
- View scheduled reminders
- Manage reminder status
- Track upcoming medication times
